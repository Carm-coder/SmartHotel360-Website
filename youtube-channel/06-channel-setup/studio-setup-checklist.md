# YouTube Studio Setup Checklist

## Customization > Profile
- [ ] Banner uploaded (2560 x 1440)
- [ ] Profile picture uploaded (800 x 800)
- [ ] Name and handle set
- [ ] Description written (from channel-description.md)
- [ ] Links added (website, socials)
- [ ] Contact email added
- [ ] Video watermark uploaded

## Customization > Home tab
- [ ] Channel trailer for non-subscribers
- [ ] Featured video for returning subscribers
- [ ] Sections / playlists arranged

## Settings > Channel
- [ ] Country of residence
- [ ] Channel keywords
- [ ] Audience setting ("made for kids" yes/no) chosen correctly

## Settings > Upload defaults
- [ ] Default description footer (links, socials)
- [ ] Default tags
- [ ] Category and language
- [ ] Default visibility: Private (publish on purpose)

## Features
- [ ] Phone verification done (custom thumbnails, long videos, live)

## Playlists
- [ ] One playlist per content pillar created
